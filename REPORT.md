# Отчёт по лабораторной работе 2

Дата проверки: 20 октября 2026 года.

Разработано десктопное приложение генерации экзаменационных билетов на Python
и Tkinter/ttk. Codex использован вместо Copilot по указанию пользователя.
JavaFX и Windows Forms не применяются.

## Изучение первой лабораторной

В `lab1` изучены консольный сценарий, генерация случайного номера, атомарное
сохранение Excel, обработка блокировки файла, тесты и дополнительная веб-версия.
Исходные 60 тестов первой лабораторной прошли. При их запуске pytest выдал
предупреждение о записи собственного кэша в папке OneDrive; сами проверки успешны.

Для второй лабораторной сохранён принцип безопасной записи через временный файл.
Добавлены загрузка групп из Excel, чтение трёх вопросов из Word, графический
интерфейс и поиск первого назначения по группе, фамилии и имени.
В итоговой ветке удалены React/Vite, сервер JSON API, веб-тесты и отслеживаемые
файлы Python bytecode. Первая версия доступна в истории Git.

## Выполненные этапы

1. Подготовлено подробное английское техническое задание `PROMPT.md`.
2. Реализованы отдельные модули данных, источников, журнала, сервиса и интерфейса.
3. Добавлены модульные тесты и проверки настоящих Tkinter-окон.
4. Подготовлены русская инструкция, запускатель Windows и входные примеры.
5. Подготовлена ветка `lab2-ui-tickets` для репозитория `lyterar/ARHIV`.

## Проверка критериев

| Требование | Проверка |
|---|---|
| Группы соответствуют листам Excel | Проверены порядок листов и принадлежность студентов |
| Кнопка требует выбора группы и студента | Проверены начальное состояние, оба выбора и смена группы |
| Пустая группа | Список пуст, кнопка неактивна, ошибок нет |
| Три вопроса из Word | Проверены корректный файл, ручные переводы строк и исходные номера |
| Некорректные билеты | Проверены неполные вопросы, неверная нумерация, дубликаты и неизвестные заголовки |
| Повтор использует первое назначение | Проверены несколько повторов, перезапуск и противоречащая более поздняя строка |
| Одинаковые имена в разных группах | Назначения независимы |
| Сохранение сразу | Файл проверен до закрытия окна результата |
| История не перезаписывается | Проверены старые строки, форматирование и дополнительные листы |
| Блокировка Excel | Проверены PermissionError и реальная блокировка открытого файла в Windows |
| Повтор сохранения | Сохраняется прежний билет, добавляется ровно одна строка |
| Повреждённый журнал | Ошибка показана, исходные байты не изменены |
| Нет источника | Главное окно остаётся открытым, повторная загрузка после исправления успешна |
| ESC | Закрывает результат, основное окно продолжает работать |
| Несколько экземпляров | Проверена блокировка транзакции на время записи |

## Демонстрационные данные

`students.xlsx` содержит три группы, из них одна пустая, и семь вымышленных записей.
Все листы просмотрены после формирования. `tickets.docx` содержит 20 билетов
с номерами 1–20, по три вопроса. Первые два вопроса взяты из учебных тем `lab1`,
третий добавлен для соответствия заданию. Парсинг всех 20 билетов проверен.
Реальный список группы и утверждённые преподавателем билеты пользователем
не предоставлялись.

## Принятые решения

При пропуске некорректного билета его номер не перенумеровывается. Случайный выбор
выполняется только среди корректных исходных номеров. Это устраняет противоречие
между диапазоном 1…N и требованием пропускать повреждённые блоки.

Если ранее назначенный билет больше не доступен в Word, программа требует
восстановить его и не выдаёт произвольно другой. При отмене неудачного сохранения
строка не появляется, а окно результата не открывается.

Журнал, логи, файлы блокировок и временные материалы исключены из Git.
Настроен GitHub Actions workflow для тестов на Windows.
